1 平台概述

PlantFlow（厂流）是一个可视化工作流编排 + AI 知识库 + 对话应用平台，面向工厂和企业内部自动化场景。可理解为 n8n（流程编排）+ Dify（AI 应用） 的开源实现。

核心能力

  • 工作流编排 — 拖拽式可视化编辑器，支持 30+ 节点类型
  • AI 能力 — 大模型对话、知识库 RAG、AI Agent 工具调用
  • 对话应用 — 把工作流发布为聊天机器人，对外提供 OpenAI 兼容 API
  • 多渠道接入 — 企业微信、飞书、钉钉消息推送与回调
  • 定时与 Webhook — Cron 定时触发、外部 Webhook 接入
  • 多租户 — 租户隔离、成员管理、审计日志

2 登录与界面

登录

  1. 访问 https://api.cloud.cenkor.cn
  2. 输入邮箱和密码
  3. 首次使用请先注册租户（注册即创建新租户）
演示账号：admin@example.com / admin123（首次登录后请立即修改密码）

界面布局

  • 左侧导航栏 — 各功能模块入口
  • 顶部栏 — 搜索、通知、用户头像（修改密码 / 退出）
  • 主内容区 — 当前页面的核心操作区域

修改密码

右上角头像 → 个人中心 → 修改密码 → 输入旧密码 + 新密码 → 确认

3 工作流管理

工作流列表

左侧导航栏 → 工作流，展示所有已创建工作流。支持搜索、筛选、排序。

创建工作流

  1. 点击「新建」按钮
  2. 从模板选择（推荐初学者使用）或从空白创建
  3. 进入编辑器后拖拽节点完成流程设计
  4. 点击「保存」，然后「发布」
注意：只有「发布」后的工作流，外部触发器（定时、Webhook、对话）才会生效。未发布的工作流只能手动运行测试。

工作流操作

操作说明
编辑进入可视化编辑器
运行手动触发执行（注入测试数据）
发布上线工作流，外部触发生效
版本历史查看历史版本，支持回滚
复制快速复制工作流
删除删除工作流（不可恢复）

界面分区

区域说明

中间画布可视化拖拽编辑区域，节点 + 连线构成工作流
右侧配置面板选中节点后在此配置参数

基本操作

操作方法
添加节点左侧拖拽到画布，或点击节点库中的节点
连接节点从节点右侧的输出点拖拽到下一个节点的输入点
配置参数点击节点 → 右侧面板修改参数
删除节点/连线选中后按 Delete/Backspace
插入变量在配置面板中点击「变量选择器」选择插入
自动排列顶栏「自动排列」按钮
缩放/平移鼠标滚轮缩放、按住空格拖拽平移

变量语法

写法含义
{{trigger.content}}触发器传递的主要内容（文本）
{{trigger.firedAt}}触发时间
{{steps.__last__.text}}上一步节点的输出文本
{{steps.__last__.chunks}}上一步知识库检索结果
{{steps.节点ID.字段}}指定节点 ID 的特定字段输出
{{nodes.节点ID.字段}}同上（兼容写法）
提示：选中节点后右侧面板会显示该节点的可用输出字段。配置面板中直接输入 {{ 会弹出变量选择器。

IF 分支

逻辑 → IF 节点：配置条件表达式。绿色输出 = 条件为真，红色输出 = 条件为假。

发布流程

  1. 点击「保存」确保当前编辑内容已保存
  2. 点击「发布」创建新版本并使外部触发器生效
  3. 发布后如需修改，编辑草稿后重新发布
  4. 如需回滚，在版本历史中选择目标版本 → 回滚

6 执行中心

查看所有工作流的运行记录，用于调试和监控。

执行列表

  • 按工作流、状态、时间筛选
  • 状态标识：成功（绿色）、失败（红色）、运行中（蓝色）、已取消（灰色）
  • 点击某条记录进入详情

执行详情

  • 节点步骤 — 每个节点的输入/输出、耗时、状态
  • 错误信息 — 失败节点会显示详细错误堆栈
  • 重试 — 失败的执行可点击「重试」
  • 取消 — 运行中的执行可点击「取消」
调试技巧：在关键节点后添加「设置变量」节点，将中间变量打印出来，帮助排查数据流转问题。

7 知识库 RAG

什么是知识库

知识库用于存储企业文档，供 AI 在对话时检索引用（RAG — Retrieval-Augmented Generation）。支持关键词搜索和向量语义搜索。

创建知识库

  1. 左侧导航 → AI · 知识库
  2. 点击「创建知识库」，填写名称和描述
  3. 创建后选中该知识库（高亮显示）

导入文档

方式支持格式说明
上传文件.txt / .md / .pdf / .docx文件自动分段后导入
粘贴导入纯文本直接粘贴文本内容

检索模式

模式说明前提
关键词检索PostgreSQL 全文匹配无需额外配置，立即可用
向量检索语义相似度搜索需配置 Embedding 模型 + 文档重向量化
混合检索关键词 + 向量加权组合需配置 Embedding 模型

在工作流中使用

标准 RAG 流程：触发 → 知识库检索 → AI 对话

  1. 添加「知识库检索」节点，选择知识库和检索模式
  2. 添加「AI 对话」节点，在系统提示中引用 {{steps.__last__.chunks}}
  3. 保存并发布工作流
注意：文档导入后，需要「重向量化」才能用于向量检索。左侧列表会显示「X 已向量化」的进度。

8 对话应用

什么是对话应用

将工作流包装成一个可对外提供服务的聊天产品。支持网页聊天窗口、OpenAI 兼容 API、嵌入代码。

发布对话应用

  1. 创建一个包含「对话触发」节点的工作流
  2. 保存并发布该工作流
  3. 左侧导航 → AI · 对话应用 → 新建
  4. 选择已发布的工作流，填写应用名称
  5. 点击「发布」

对外提供服务

方式说明
聊天页面链接直接访问 /chat/:apiKey 即可对话
APIOpenAI 兼容 /api/v1/chat/completions
嵌入代码一行 JS 代码嵌入到任何网站

API 调用示例

curl https://api.cloud.cenkor.cn/api/v1/chat/completions \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'

9 AI 模型配置

配置路径

左侧导航 → AI · 模型

配置步骤

  1. 点击「添加提供商」
  2. 填写：名称、Base URL、API Key
  3. 填写 Chat 模型名称（如 gpt-4o、deepseek-chat）
  4. 可选：填写 Embedding 模型名称（如 text-embedding-3-small）
  5. 点击「设为默认 Chat 模型」或「设为默认 Embedding 模型」
  6. 保存后点击「测试」验证连通性
重要：Chat 能通 ≠ Embedding 能通。如果网关不支持 /embeddings 接口，知识库请使用关键词检索模式。

多个模型

可以配置多个提供商并在不同工作流中使用。每个工作流的 AI 节点可以选择使用的模型。

10 渠道接入

支持的渠道

  • 企业微信 — 消息推送与回调
  • 飞书 — 事件回调与消息推送
  • 钉钉 — 消息推送与回调

配置步骤（以飞书为例）

  1. 左侧导航 → 渠道接入 → 飞书
  2. 填写 App ID、App Secret
  3. 保存后复制回调地址，在飞书开放平台配置事件回调
  4. 点击「测试发送」验证连通性

在工作流中使用

  • 触发 — 使用「飞书触发」节点，当用户在飞书向机器人发消息时触发工作流
  • 推送 — 使用「消息推送」节点，选择飞书渠道和接收方式（chat_id / user_id）
配置回调地址格式：https://你的域名/api/channels/feishu/webhook/:tenantId

11 连接器与凭证

连接器

连接器用于复用 HTTP 鉴权配置。在「HTTP 请求」节点中可直接选择已配置的连接器，避免重复填写认证信息。

凭证管理

存储 OAuth2 / API Key 等敏感凭证，供工作流节点安全使用。凭证内容经过 AES-256-GCM 加密存储。

12 会话中心

查看所有通过渠道接入的对话记录，支持人工回复。

  • 按租户、渠道、时间筛选会话
  • 点击会话查看消息历史
  • 点击「回复」输入人工回复内容
  • 可修改会话状态（待处理 / 处理中 / 已完成）

13 Prompt 模板

管理和复用提示词模板，支持版本控制。

  1. 左侧导航 → AI · Prompt 模板
  2. 创建模板，填写名称和内容（支持变量 {{变量名}}）
  3. 在工作流的 AI 节点中可选择该模板
  4. 修改模板后创建新版本，历史版本可回溯

14 常见问题

AI 对话没有回复

检查执行中心 → 确认工作流已发布 → 检查 AI 模型配置是否正确 → 测试模型连通性

知识库检索无结果

先切换为「关键词检索」模式确认文档已导入。如需向量检索，配置 Embedding 模型后执行「重向量化」。

定时任务没有触发

确认工作流已「发布」。发布后的工作流才会注册 Cron 定时器。

飞书/企微发不出消息

检查渠道配置是否正确，接收方 chat_id / user_id 是否有效。测试发送功能可以快速验证。

工作流运行失败

在执行中心查看失败节点的错误信息。常见原因：变量引用错误、HTTP 请求超时、AI 模型不可用。

如何重置密码

右上角头像 → 个人中心 → 修改密码。如需管理员重置，联系平台管理员操作。
