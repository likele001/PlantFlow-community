关键度量与风险

关键度量（每迭代必须看）

  • Agent 任务成功率 ≥ 90%（工具调用全成功）
  • Agent 平均响应时长 P95 ≤ 6s（含工具调用）
  • 队列积压 0 持续超过 5 分钟
  • 多 Agent 一次完成率 ≥ 70%（不需用户追问）
  • 模板导入转化率 ≥ 40%
  • 一线员工周活（用 IM 调 Agent 的次数 / 人 / 周）

风险与缓解

  • LLM 成本失控：每工具调用限长 / 每会话 token 上限 / 缓存高频查询
  • 越权：DataAccess 层强制 scope，所有工具调用带 tenant_id；F4 必做
  • Agent 死循环：F2 强制总轮数 + 单轮超时
  • 第三方 API 限频：连接器 SDK 内置限频与退避
  • 多 Agent 上下文爆炸：上下文压缩 + 摘要 + 只传必要数据
